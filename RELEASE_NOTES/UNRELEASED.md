# Unreleased

v0.2.0以降に行われた、自治体ソース検証の厳格化（実抽出プローブ導入）、佐賀県全20自治体のプロファイル整備、議事録・例規アダプターの拡張、共通パーサー・ユーティリティの集約リファクタリング、検索・検算の堅牢化を記録する。

## Added

- **実抽出プローブ（Extraction Probe）による検証ゲート厳格化**:
  - `source_profiles.verify` に実文書の取得・検証（1件抽出テスト）を必須化。HTML上のリンク存在だけでなく、実際の文書が取得・解析できる場合のみ `ready` へ昇格する昇格ゲートを導入。
  - `robots.txt` 拒否やホストドリフト（別ドメインへの意図しないリダイレクト）を検知した場合、自動的にブロック/ダウングレードする保護を追加。
- **オンデマンド・ソース解決 CLI**:
  - `python3 -m source_profiles.cli resolve` サブコマンドを追加し、自治体名から該当ソースプロファイルを即座に引けるように改善。
- **自治体カバレッジの大幅拡充（佐賀県全20市町）**:
  - 佐賀県全20自治体について、議事録・例規・予算・決算のプロファイル整備と検証ステータスを更新。
- **議事録（`minutes_db`）アダプターと機能の拡張**:
  - 議事録システム（dbsr）アダプターの追加。
  - 静的アダプターでの複数階層リンク追跡（multi-level follow）および `<B>` タグ発言者マーク抽出に対応。
  - 壊れた文書をスキップして取込を継続する `--skip-broken-documents` フラグを追加。
  - 会期・号数の欠落や不整合を検出する `completeness` 診断機能を追加。
- **例規（`regulations`）アダプターの拡張**:
  - Joureikun および D1-Law フレーム型例規アダプターを追加。
  - リクエスト負荷を制御する `--min-interval` オプションを追加。
- **オンボーディング検証のネガティブパステスト追加**:
  - `verify_scaffold` の異常系・境界条件テストを追加。

## Changed / Refactored

- **HTMLリンクパーサーの集約 (`lcaios.html.LinkParser`)**:
  - `bootstrap/cli`、`minutes_db/detect`、`source_profiles/cli` に分散・重複していた4つのリンク抽出パーサーを `lcaios.html.LinkParser` に一本化。
- **テキスト・識別子生成の集約 (`lcaios.text`)**:
  - 和暦西暦変換（`era_to_year`）、文字列正規化（`collapse_whitespace`）、ハッシュベースの `stable_id`（prefix + 可変長引数）を `lcaios.text` に集約。未使用の `collapse_fullwidth` を削除。
  - 予算・決算・議事録のローカルなID生成実装を共有ヘルパーへ統合。
- **HTTP共通処理の集約 (`lcaios.http`)**:
  - `canonical_url` を `strict` フラグ付きで公開関数として統一。
  - キャッシュキーの秘匿化および初回取得優先セマンティクスを明文化。
- **レビュー・検算共通モジュール (`modules/_review_common.py`)**:
  - 予算・決算レビューで重複していた空文字正規化・数値変換・ロケーター生成・`sha24` 算出ロジックを抽出・集約。
- **例規パーサーの共通化 (`modules/regulations/_parsers.py`)**:
  - 各ベンダーアダプターで重複していたフレーム・リンク解析処理を共通化。
- **JISチェックディジット算出の単一化**:
  - 3箇所に分散していた自治体コードのチェックディジット計算を `expected_code` に集約。
- **ドキュメント・データ規約の重複排除**:
  - `way-of-working`、`data-contracts`、各モジュールREADME間で重複していた記述を整理し、単一の情報源を参照する構造へリファクタリング。

## Fixed

- **FTS検索フォールバックの限定**:
  - `minutes_db` および `regulations` の検索において、構文エラーやテーブル未存在など想定内の事象でのみ LIKE 検索へフォールバックし、DB破損やディスク障害時はエラーを隠蔽せず適切に報告するよう修正。
- **決算検算（`settlement_review`）の繰越額突合**:
  - 節レベルがなく目レベルのみに翌年度繰越額が存在するケースを許容するよう突合ルールを調整。
- **議事録取込の整合性維持**:
  - 同一文書の再取込時に古い発言レコードが残存する不具合を修正。
  - 発言者ヘッダ判定から手続的文言を除外、推定日付の明示マークを付与。
- **予算取込（`budget_review`）の金額フォールバック**:
  - 親要素と子要素で金額フォールバック挙動の不一致を解消。
- **HTTP文字コードフォールバック順序**:
  - Charset未宣言レスポンスのフォールバックにおいて、cp932 より前に EUC-JP を優先評価するよう修正。
- **ベンチマーク集計の単位整合**:
  - 単位（千円/円等）を考慮したランキング算出と、公表時点（as_of）の反映処理を適正化。

## Safety & Policy

- **発見（Discovery）と検証（Verification）の境界厳格化**:
  - preflightによる自動探索は「候補の提案」に留め、文書の実抽出プローブ（verification）を経たもののみを `ready` として扱う境界を徹底。
- **個別認証・Cookie必須システムのスコープ切り分け**:
  - セッションCookieや個別認証が必要なベンダーアダプター（D1-Law特定構成等）は標準リポジトリのスコープ外（各議員・自治体の個別関心事）として整理。
- **不要コード（Dead Code / No-op）の完全排除**:
  - 監査に基づき、参照されていないパスや無効な処理を徹底的に削除。

- Python 3.11 環境での静的解析・型チェック（mypy / ruff）をクリア。
