# v0.4.0

v0.3.0以降に行われた、自治体データ見取り図（MOC）機能の追加、オンボーディングの疎結合化（Obsidian必須解除・エディタ自由化）、多年度予算決算ブリッジ分析モジュールの新設、HTTP 429/503 自動バックオフ機構、および決算多年度審査実務ワークフローの整備を記録する。

## Added

- **自治体データ見取り図（MOC）生成コマンド (`lcaios dashboard`)**:
  - 手元の議事録・例規・決算・比較指標データベースを自動走査し、収録期間・発言数・最新決算総括表をまとめた `00_自治体データ見取り図.md`（および JSON レポート）を生成・更新する CLI を追加。
  - Obsidian の Dataview や手動棚卸しに依存せず、常に最新の自治体データ見取り図を 1 コマンドで把握可能。
- **多年度予算決算ブリッジ分析モジュール (`modules.settlement_review.bridge`)**:
  - 複数年度の決算データ（R4〜R7等）から、**不用額常態化（見積もり過大・前年踏襲）**、**連続繰越（事業停滞）**、**歳入未収金・不納欠損** を 0 トークン・一瞬で抽出する独立計算機モジュールを追加。
  - 人間がそのまま読める Markdown 表形式出力と、LLM プロンプトに直接渡せる JSON 構造化出力の両方に対応。
  - テストDB（`settlement_expenditure`）と本番DB（`expenditure`）のスキーマ差分を自動判定・吸収。
- **取込パイプラインの堅牢化 (`HttpClient` 429/503 自動 Backoff)**:
  - 自治体サイトや例規サーバーからのレートリミット（HTTP 429）および一時的過負荷（HTTP 503）に対して、`Retry-After` ヘッダー待機および指数バックオフ（最大3回リトライ）を自動実行する機能を追加。
- **実務ワークフロー追加 (`workflows/08-settlement-budget-review.md`)**:
  - 9月決算特別委員会（不用額常態化の是正要求）から3月予算特別委員会（当初予算案の見積もり適正化）までをつなぐ実務手順書とプロンプト断片を追加。
- **公開調査ワークフローの更新 (`workflows/03-public-research.md`)**:
  - 調査の冒頭で `00_自治体データ見取り図.md` を確認し、収録期間外の議論を「議論されていない」と誤認しないための手順を追加。

## Changed / Improved

- **オンボーディングの疎結合化（Obsidian必須縛りの解除）**:
  - Obsidian CLI や `.obsidian` 設定フォルダが存在しない環境でも、`CLAUDE.md` または `AGENTS.md` が配置された任意の Markdown フォルダ（VS Code / Cursor / Neovim 等）において、`integrate` モードで棚・MOC・テンプレートの scaffold を安全に実行できるよう制約を緩和。
  - `lcaios status` および `lcaios doctor` において、`foundation_ready` の判定を「有効なワークスペース + AIガイドファイルの存在」に基づく柔軟な判定へと更新。
- **ドキュメントの最新化**:
  - `README.md` のコア機能を 4 大機能へ拡充、クイックスタートに多年度ブリッジ分析と見取り図生成を追加、テスト件数を 500+ tests へ更新。
  - `onboarding/README.md`、`modules/budget_review/budget_settlement_bridge.md` の記述を実装と整合。
