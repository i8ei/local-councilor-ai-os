# Release v0.6.0 — EBPM質問・政策設計ワークフローと決算・議事録自動照合パイプライン

**Release Date:** 2026-08-28

## 概要

`v0.6.0` では、従来の「見立て・ツボ・手当て」から、総務省・内閣府等でも採用される公的な共通言語 **「EBPM（証拠に基づく政策立案）」体系への全面移行** を行いました。

多年度決算データと議事録全文検索を組み合わせ、不用額常態化（前年踏襲）や歳入未収金から、エビデンス・ロジックモデル・政策提言・検証KPIが揃った **「EBPM質問設計カード」をワンコマンドで自動生成するパイプライン** を新設しました。

---

## 主な新機能 (Features)

### 1. EBPM（証拠に基づく政策立案）質問設計ワークフロー
- **`workflows/ebpm-policy-design.md`**: エビデンス収集 → ロジックモデル分析 → 政策提言・質問設計 → アウトカム指標（検証KPI）の4段階からなる地方議会向けEBPM実務手順書。
- **`templates/ebpm-question-card.md`**: 標準EBPM質問設計カードテンプレート。
- **公式実例集 (`templates/examples/`)**:
  - `ebpm-card-disability-welfare.md`: 障害福祉費不用額常態化（4年で4億円不用）に対する町独自在宅支援シフト案。
  - `ebpm-card-fixed-asset-tax.md`: 固定資産税未収金および不納欠損急増に対する早期機構移管ルール化案。

### 2. 自治体財政における「4大類型パターン」と「3大原則」の確立
- **4大類型パターン**:
  1. 国県随伴・過大見積もり型（障害福祉・生活保護等）
  2. 受診・申請乖離型（予防接種・各種健診等）
  3. 補正代替・形骸化型（予備費等）
  4. 滞納固定化・時効消滅型（固定資産税等）
- **建設的提言をつくる3大原則**:
  1. 多年度決算推移（4カ年）で構造的な傾向を共有する
  2. 過去答弁の経緯（議事録照合）を踏まえて前提のズレをなくす
  3. 単なる予算削減ではなく「独自施策への再配分（住民還元）」を提案する

### 3. 決算ブリッジからの「EBPMカード一発生成」 (`bridge.py`)
- `python3 -m modules.settlement_review.bridge` に `--format ebpm-card` および `--ebpm-out-dir` オプションを追加。
- 多年度決算から不用額常態化科目および歳入未収金科目のEBPMカード（Markdown）を一括出力可能に。

### 4. 議事録過去答弁の「自動照合・引用差し込み」パイプライン
- `bridge.py` に `--minutes-db` オプションを追加。
- 不用科目のキーワードで手元の議事録DB（SQLite/FTS5）を最新日付優先で自動検索し、担当課長や首長の最新答弁をEBPMカードのエビデンス欄へ自動引用。

### 5. ドキュメント & README の全面刷新
- `README.md`: 埋め草・不要表現を徹底的に削ぎ落とし、EBPMを軸とした簡潔・明快な構成へ全面リライト。
