# Release v0.8.0 — 2層データアーキテクチャ・過年度決算自動取込・国勢調査比率拡充

**Release Date:** 2026-08-29

## 概要

`v0.8.0` では、全国1,741自治体を即座にカバーする「第1層（マクロ基盤）」と、自治体固有の深掘りを行う「第2層（ミクロ基盤）」の**2層データアーキテクチャ**を確立しました。
総務省ポータルからの複数年度決算データ自動探索・取込（`vendor_soumu`）、決算カードXLSX自動抽出（`vendor_card`）、静的議事録PDFの親見出し結合、国勢調査4年齢区分比率の同時取得を実装し、佐賀県全20市町で100%の差額0円検算合格を実証しました。

---

## 主な新機能 (Features)

### 1. 総務省ポータル過年度決算の自動探索・取込・検算 (`vendor_soumu.py`)
- 総務省の「地方財政状況調査関係資料」ポータルから、指定した複数年度（例: 2022, 2023, 2024）の市町村別決算概況XLSXを自動探索・ダウンロード。
- 自治体名（市/区 vs 町/村）から「都市別」と「町村別」のXLSXを自動判定し、`summary`, `revenue`, `expenditure` の3表を生成して `settlement.db` にインジェスト。
- 取込直後に `verify_totals` で差額0円検算を自動実行。

### 2. 決算カードXLSXからの3表自動抽出コンバーター (`vendor_card.py`)
- 自治体や総務省が公表する決算カード（Excel）から、標準ライブラリのみで `summary.csv`, `revenue.csv`, `expenditure.csv` を自動抽出。
- PDFの手作業パースを介さず、1秒で差額0円の決算データベースを構築可能に。

### 3. 国勢調査 人口ピラミッド4指標の同時抽出 (`bootstrap/cli/census.py`)
- 単一の統計表（`0003445163`）から追加HTTP通信ゼロで、以下の4指標を同時抽出：
  - **年少人口比率**（15歳未満）
  - **生産年齢人口比率**（15〜64歳）
  - **高齢化率**（65歳以上）
  - **後期高齢化率**（75歳以上）

### 4. 静的PDF議事録アダプターの親見出し結合 ＆ 会議名補完 (`static_html.py`)
- 自治体HPの階層構造から親セクション見出し（例: 「令和6年第3回定例会」）を自動追跡し、日付のみのPDFリンク（例: 「9月9日.pdf」）と結合して正確な会議名を生成。
- 見出しがない場合も、PDF本文先頭から会議名（「令和〇年〇月〇日開会」等）を自動抽出して補完。
- `link_include_regex` / `link_exclude_regex` による本会議本文の確実なフィルタリング。
