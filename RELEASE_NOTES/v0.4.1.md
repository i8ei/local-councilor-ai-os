# Release Notes: v0.4.1 (2026-08-27)

`v0.4.1` では、AIエージェントが過去の検討経緯や自分の決定事項を0秒で思い出せるようにするための「ローカル記憶インデックス（参考実装）」と「エージェント指示書用スニペット」を追加しました。

---

## 🌟 主な新機能・改善点

### 1. ローカル記憶インデクサー参考実装 (`tools/vault_indexer.py`)
- **ゼロ外部依存（標準ライブラリのみ）**: Python 3.11+ の `sqlite3`（FTS5）、`pathlib`、`argparse` だけで動作。
- **完全ポータブル**: 任意のMarkdownフォルダ（Obsidian Vault等）を `--vault` で指定して1秒で全文検索DB（`.vault_index.db`）を構築。
- **ハイブリッド高速検索**: FTS5（trigram/unicode61）と短語LIKEフォールバックを組み合わせ、2文字の日本語キーワード（例: 「福祉」「減額」）も確実に検索可能。
- **リンクグラフ**: `links`（発リンク一覧）および `backlinks`（被リンク逆引き）に対応。

### 2. エージェント記憶先引きスニペット (`templates/agent-memory-rule-snippet.md`)
- 既存の `CLAUDE.md` や `AGENTS.md` の末尾に貼り付けて使用できる、オプショナルな1段落の指示文パーツ。
- AIに「回答・起草の前にまず手元のローカル記憶を検索して過去の文脈を確認する」行動規範（先引きゲート）を付与。

### 3. 作業美学とワークフローの強化
- **`way-of-working/10-personal-operating-style.md`**: 「AIを『文脈を持たない天才』にしない（ローカル記憶の先引き）」節を追加。
- **`workflows/01-start-case.md`**: 案件開始ステップに手元の過去ノート・記憶の先引き確認を追記。
