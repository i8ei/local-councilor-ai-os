# 08 決算多年度審査と予算ブリッジ

## 要旨

単年度の「数字合わせ（検算）」にとどまらず、多年度の決算データ（R4〜R7など）を横断分析し、**「不用額の常態化（予算の過大計上・前年踏襲）」「複数年連続の繰越（事業停滞・入札不調）」「歳入の未収金・不納欠損」** を政策的に突く質疑を組み立てる。

重い計算や足し引きはローカルの分析計算機（`bridge.py`）に任せて0トークン・瞬時に抽出し、LLM（AI）には「行政への是正要求・答弁追跡・質疑ツリーの推敲」だけに集中させる。

## 発動条件

- 9月の決算審査（決算特別委員会・分科会）で、行政の予算執行や見積もりの妥当性を審査するとき
- 3月の当初予算審査（予算特別委員会）で、新規・継続事業の予算規模が過去の決算実績に見合っているかを検証するとき
- 決算データが `modules/settlement_review` で検算済み（差額ゼロ）であること

## 入力と前提

- 検算済みの決算SQLiteデータベース（例: `decsan_r4_r7.db`）
- `modules.settlement_review.bridge` の分析出力（Markdown または JSON）
- 当該事業に関する過去の議事録・例規（`minutes_db` / `regulations`）
- 当該年度の主要施策成果説明書または事務報告書

## 手順

1. **【ツール】多年度ブリッジ分析を実行する。** ローカルの分析計算機を使い、複数年で基準（例: 2年以上、不用額100万円以上、不用率15%以上）を超える事業を抽出する。
   ```bash
   python3 -m modules.settlement_review.bridge \
     --db /path/to/decsan.db \
     --min-years 2 \
     --min-unused-amount 1000000 \
     --min-unused-rate 0.15
   ```

2. **【人】重点審査対象（3〜5事業）を選定する。** 出力されたリストから、金額規模、不用率、政策的重要性（福祉・産業・教育など）を考慮し、審査で取り上げる事業を決定する。
   - **過大計上型**: 毎年多額の不用額が継続している（例: 企画財政管理費、予防費）
   - **事業停滞型**: 2年連続で翌年度繰越が発生している（例: 道路維持費、施設整備）
   - **徴収課題型**: 収入未済額が年々増加している（例: 固定資産税、使用料）

3. **【AI】不用額・繰越の推移から質疑ツリーの草案を作る。** 抽出された推移データをAIに渡し、担当課への質疑ポイント（見積もり根拠、執行見込みの甘さ、制度的ボトルネック、基金への死蔵）を整理させる。

4. **【併走】過去の議事録答弁と照合する。** 同一事業について過去の議会で「なぜこの予算が必要なのか」「いつまでに執行するのか」とどう答弁していたかを `minutes_db` で検索し、答弁の変遷と矛盾がないかを確認する。

5. **【人】決算審査の質疑メモ・意見開陳を確定する。** 事実（過去○年の不用額・繰越実績）と要求（次年度予算での見積もり見直し、執行体制の改善）を明確に分けた質疑メモを執筆する。

6. **【人・追跡】翌年3月の当初予算案へ接続（ブリッジ）する。** 9月の決算審査で指摘した事業について、翌年3月に提出された新年度予算案で適正な規模へ減額・見直しが行われたかを照合する。見直しが不十分な場合は、予算委員会での質疑へ直接引き継ぐ。

## プロンプト断片

```text
以下の多年度決算データ（不用額の推移）に基づき、9月決算特別委員会で担当課に問い質すための「質疑ツリー」を作成してください。

【対象事業の推移】
{{bridge.pyで抽出された対象事業の表を貼り付け}}

【作成要件】
1. 主質問: 複数年連続で多額の不用額（不用率○%）が発生している構造的要因（見積もりの甘さ、受診率・利用率の見込み違い、契約差金など）の確認
2. 再質問の分岐:
   - 「事業計画の変更や突発的事態によるもの」と答弁された場合 ➜ 「複数年連続で発生している理由と前年踏襲の見積もり是正」を突く問い
   - 「契約差金や執行残である」と答弁された場合 ➜ 「次年度当初予算での予算枠縮小や他事業への財源充当」を迫る問い
3. 求める回答形式（数値、期限、見直し方針）を明記してください。
```

```text
以下の決算指摘事項について、3月当初予算案の査定状況を確認するための「予算審査チェックシート」を作成してください。

【決算審査での指摘】
{{9月決算審査で指摘した事業名と不用額の推移}}

【新年度当初予算案】
事業名: {{新年度事業名}}
要求額・計上額: {{新年度予算額}} 円（前年度比: {{増減額}} 円）

【確認事項】
1. 決算での不用額実績を踏まえた減額修正がなされているか
2. 依然として過大計上が継続している場合の予算委員会質疑案
```

## 成果物と完了条件

- 複数年の決算実績（予算・執行・不用・繰越）に裏打ちされた決算審査質疑メモ
- 9月の決算指摘から翌年3月の予算審査への追跡記録（予算決算ブリッジメモ）
- すべての金額が `settlement_review` で検算済みの数値と1円単位で一致していること

## アンチパターン

- **単年度の不用額だけで過大計上と断定する。** 一時的な入札差金や国県補助金の減額など突発的要因の可能性があるため、必ず複数年推移で見る。
- **決算書の数字をLLMにすべて読ませて計算させる。** LLMは四則演算でミスをするため、集計は必ず `bridge.py` に任せ、LLMには思考と文章化だけを行わせる。
- **9月決算の指摘をその場で終わらせる。** 決算審査の価値は「次年度予算の是正」にあるため、3月予算審査まで追跡を怠らない。
