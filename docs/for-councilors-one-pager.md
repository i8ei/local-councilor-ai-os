## 3. 実践実例（佐賀県太良町での実証モデル）

手元のPCで決算データと議事録を読み込ませるだけで、以下のような「質問設計カード」が**一瞬で自動生成**されます。

```markdown
# 【EBPM質問・政策設計カード】障害福祉費の不用額分析と町独自支援へのシフト

## ① エビデンス（客観的な数字と過去答弁）
- 令和4年度: 不用額 6,242万円 (不用率 10.5%)
- 令和5年度: 不用額 1億1,595万円 (不用率 19.7%)
- 令和6年度: 不用額 1億3,739万円 (不用率 21.4%)
- 令和7年度: 不用額 8,464万円 (不用率 13.9%)
> 【事実】4年間で累計 4.0 億円が不用。町単独の一般財源だけでも毎年約2,000万円が失効。
> 【過去答弁】令和7年決算委員会「受給者数の見込みが過大だった...」

## ② 政策提言（建設的な改善アクション）
- 質問1: 「4年連続・累計4億円の不用額が生じている当初見積もりの要因は？」
- 質問2: 「直近の実績に基づいた精緻な当初予算計上へ改める考えは？」
- 質問3: 「浮いた町の一般財源（約2,000万円）を活用し、在宅重度障害者のレスパイトケアや移動支援などの町独自助成へシフトできないか？」

## ③ アウトカム指標（次回決算での検証目標）
- KPI 1: 翌年度決算における障害福祉費の不用率を 10% 未満へ適正化
- KPI 2: 独自助成によるレスパイトケア新規利用 年間20件以上を達成
```

## 4. 3つの安心・特徴

1. **完全無料・オープンソース（OSS）**:
   大手コンサルやシステム会社に高額な費用を払う必要はありません。誰でも無料で使えます。
2. **安心の完全ローカル（ゼロ外部依存）**:
   住民相談の記録や議会の未公開メモが外部クラウドに漏洩するリスクはゼロ。手元のノートPC内だけで安全に完結します。
3. **全国1,741自治体に対応**:
   全国すべての市町村・都道府県の公開データに対応した設計になっています。
