# 【EBPM質問・政策設計カード】障害福祉費の不用額常態化と在宅独自支援へのシフト

- **対象自治体**: 例自治体（佐賀県太良町実証モデル）
- **会計・科目**: 一般会計 3款1項2目 障害福祉費（自立支援給付事業等）
- **作成日**: 2026-08-28
- **担当課**: 健康増進課（福祉係）

## 1. エビデンス（事実・データ・過去答弁）[Evidence]

### ① 4カ年決算推移
- **令和4年度**: 予算現額 594,680,000 円 / 支出済額 532,253,712 円 / 不用額 **62,426,288 円** (不用率 `10.5%`)
- **令和5年度**: 予算現額 588,304,000 円 / 支出済額 472,348,856 円 / 不用額 **115,955,144 円** (不用率 `19.7%`)
- **令和6年度**: 予算現額 641,071,000 円 / 支出済額 503,679,434 円 / 不用額 **137,391,566 円** (不用率 `21.4%`)
- **令和7年度**: 予算現額 609,137,000 円 / 支出済額 524,487,853 円 / 不用額 **84,649,147 円** (不用率 `13.9%`)

> **4年間累計不用額**: **400,422,145 円（約 4.0 億円）** / 年平均 不用額 **100,105,536 円**

## 2. ロジックモデル分析（因果関係・ボトルネック特定）[Logic Model]

```text
【インプット（投入）】
  ・毎年度当初予算に前年踏襲で約 5.9億〜6.4億円 を計上
  ・財源構成: 国 50% / 県 25% / 町 25%（町単独一般財源: 年間約 1.5億円）
      │
      ▼
【アクティビティ（活動）】
  ・障害福祉サービス（居宅介護、重度訪問、就労支援等）の支給決定および事業者報酬支払
      │
      ▼
【アウトプット（直接実績）】
  ・実執行額: 約 4.7億〜5.3億円（毎年度 6,200万〜1.37億円 が未執行・不用）
  ・町単独一般財源の余剰拘束: 毎年 1,500万〜3,400万円 が使われないまま年度末に失効
      │
      ▼
【ボトルネックの特定】
  1. 【前年踏襲型過大計上】受給者の高齢化や施設入所等の実利用実績と、当初予算見積もりの乖離
  2. 【制度の谷間】在宅重度障害者のレスパイトや移動支援など、国の給付基準外の町独自支援枠が未整備
```

## 3. 政策提言・質問項目（アクション）[Policy Action]

### 質問 1（事実確認・インプット精査）
> 「障害福祉費において過去4年連続で合計4億円（年平均1億円）の不用額が生じている。町単独の一般財源だけでも毎年1,500万〜3,400万円が使われないまま拘束されている計算となるが、当初予算見積もりの算出根拠と過大計上の要因をどう総括しているか？」

### 質問 2（予算編成の見直し）
> 「翌年度当初予算においては前年踏襲を排し、直近2カ年の実受給実績に基づいた精緻な当初計上を行い、不測の増額には補正予算で対応する弾力的な予算編成へ改める考えはないか？」

### 質問 3（政策提言・独自施策へのシフト）
> 「不用額として浮く町単独一般財源（約2,000万円）を活用し、町独自の『在宅重度障害者レスパイトケア助成』や『福祉有償運送・移動支援の助成拡大』など、制度の谷間にある町民への独自支援にシフトすべきではないか？」

## 4. アウトカム指標（検証KPI）[Outcome KPI]

- **次回（翌年度）決算審査での検証目標**:
  - **KPI 1（予算適正化）**: 障害福祉費の不用率を **10.0% 未満**（不用額 5,000万円以下）へ圧縮
  - **KPI 2（独自支援創出）**: 不用財源を活用した町独自レスパイト・移動支援の新規利用件数 **年間 20 件以上** を達成
