# 【EBPM質問・政策設計カード】固定資産税の未収金縮減と不納欠損（時効消滅）防止策

- **対象自治体**: 例自治体（佐賀県太良町実証モデル）
- **会計・科目**: 一般会計 歳入 1款2項 固定資産税
- **作成日**: 2026-08-28
- **担当課**: 税務課（徴収係）

---

## 1. エビデンス（事実・データ・過去答弁）[Evidence]

### ① 4カ年決算推移
- **令和4年度**: 調定額 398,365,045 円 / 収入済額 381,028,584 円 (徴収率 `95.6%`) / 未済額 **16,760,254 円** / 不納欠損額 576,207 円
- **令和5年度**: 調定額 410,556,254 円 / 収入済額 395,430,307 円 (徴収率 `96.3%`) / 未済額 **14,365,147 円** / 不納欠損額 760,800 円
- **令和6年度**: 調定額 403,076,047 円 / 収入済額 390,521,865 円 (徴収率 `96.9%`) / 未済額 **11,813,882 円** / 不納欠損額 740,300 円
- **令和7年度**: 調定額 398,411,282 円 / 収入済額 386,084,954 円 (徴収率 `96.9%`) / 未済額 **10,309,028 円** / 不納欠損額 **2,017,300 円**

> **重要事実**: 令和7年度は徴収率96.9%と横ばいながら、**不納欠損額（時効消滅）が 2,017,300 円と前年（74万円）の2.7倍に急増**。

### ② 過去の議会答弁
- **決算審査特別委員会 税務課長 答弁**:
  > 「県内市町で比較すると最下位水準。未収金の状況は前年より改善しているが、依然として高水準が続いている...」

## 2. ロジックモデル分析（因果関係・ボトルネック特定）[Logic Model]

```text
【インプット（投入）】
  ・税務課徴収体制、督促状・催告書の送付、県地方税滞納整理機構への負担金
      │
      ▼
【アクティビティ（活動）】
  ・定期的な督促状発送、窓口・電話催告、一部大口滞納者の機構移管
      │
      ▼
【アウトプット（直接実績）】
  ・年間調定額約4億円に対し、毎年1,000万〜1,600万円が未収のまま滞納繰越
  ・5年時効到来による不納欠損が毎年数十万〜200万円発生
      │
      ▼
【ボトルネックの特定】
  1. 【初期催告の遅延】滞納1〜2年目の初期段階での接触・資産調査が不足し、固定化
  2. 【情報分断】空き家バンク・相続登記情報（企画課・住民課）と税務課固定資産台帳の連携不足による所有者特定遅延
  3. 【機構移管基準の曖昧さ】県滞納整理機構への移管が後手に回り、時効直前で持ち込まれる
```

## 3. 政策提言・質問項目（アクション）[Policy Action]

### 質問 1（事実確認・不納欠損急増の要因）
> 「令和7年度の固定資産税不納欠損額が201万円と前年比2.7倍に急増した主たる理由（大口案件の時効到来か、滞納処分の執行停止か）は何か？」

### 質問 2（早期移管ルールの制度化）
> 「滞納の長期固定化を防ぐため、県地方税滞納整理機構への移管基準を『滞納〇年超または滞納額〇〇万円以上は自動的に移管対象とする』等、客観的な数値基準でルール化できないか？」

### 質問 3（空き家・相続情報の庁内横断連携）
> 「企画政策課の空き家対策および法務局の相続登記義務化情報と連携し、所有者不明土地・家屋の法定相続人を早期に特定して課税・適正徴収へつなげる庁内照会フローを構築すべきではないか？」

## 4. アウトカム指標（検証KPI）[Outcome KPI]

- **次回（翌年度）決算審査での検証目標**:
  - **KPI 1（不納欠損の抑制）**: 令和8年度決算における固定資産税の不納欠損額を **100万円未満** に半減
  - **KPI 2（機構移管の強化）**: 県滞納整理機構への新規移管件数を **年 5 件以上** へ倍増
