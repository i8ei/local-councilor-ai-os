# エージェント指示書向け 記憶先引きスニペット（参考用）

> ご自身の `CLAUDE.md` や `AGENTS.md` の末尾に貼り付けて使用できるオプショナルな指示文です。
> AIがセッションをまたいで過去の文脈や判断を思い出せるようになります。

```markdown
## ローカル記憶の先引きルール（文脈の固定）
- 質問設計、政策調査、過去の判断を扱う際は、AI自身が勝手に推測せず、手元のローカル記憶（過去の質問ノート、住民相談メモ、決定ログ）を先に検索して文脈を確認する。
  - 検索例: `python3 tools/vault_indexer.py search "<キーワード>"`（または手元の全文検索コマンド）
- 過去のノートに決定事項や言質がある場合はそれを優先し、セッションをまたいで一貫した文脈で回答・起草する。
```
